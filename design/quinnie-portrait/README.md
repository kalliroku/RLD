## 드롭인 호환 — 형제 흉상(레플리/리카)과 동일 골격 ★

father(scale=4, 전신)는 기준 부적합. **레플리·리카(scale=6, waist-up 흉상)** 에 맞춤:

- **시그니처**: `(ctx, cx, baseY, scale = 6)` — child/repli/rika 와 동일.
- **흉상(BUST)**: 다리·발 없음. **torso 바닥 = `y 0` = baseY**(허리 크롭). baseY 는 발밑이 아니라 흉상 하단선. *(브리프 §4 는 "발밑 기준"이라 적었으나 실제 형제 코드는 모두 허리 크롭 흉상 — 형제 코드 기준으로 맞춤.)*
- **표준 골격**(형제와 동일 좌표대): torso `-19..0`(폭 ~12) · neck `-21..-19` · head `-33..-21`(10×12) · **눈높이 `y=-29`** · 코 `~-26` · 입 `~-24` · 머리/모자/귀는 `-33` 위.
- **광원**: +x 횃불 측 lit / −x shadow. 광원·페이드·딤은 호출부(`_drawGuildScene`) 소유.
- **팔레트**: `R(x,y,w,h,c)` fillRect + **함수 상단 로컬 색 토큰**(형제 방식 — repli 하늘색/금발, rika 분홍처럼 캐릭터색은 로컬 hex). raster 이미지/임베드 색 신규 도입 없음.
- **검증**: 미리보기의 `eyeline` 토글로 셋의 눈높이가 `y=-29` 한 줄에 맞음을 확인.

## 디자인 의도 (브리프 §3·§6 + bm v1 피드백 반영 = v2)

- **갈색 강아지 수인 여성, 인간형 본체**: 종족 신호 = 얼굴 옆으로 넓게 처지는 **늘어진 개 귀(drop ear)** ← v1 의 높고 뾰족한 귀가 "다람쥐"로 읽혀 교정. **한쪽 끝만 접어** 덜렁이 유지. 허리 크롭 아래로 **가늘고 긴 개 꼬리**(v1 북슬 덩어리 → 슬림). 옆 포니테일 볼륨 제거(다람쥐 꼬리 인상 제거) → 뒤통수 작은 묶음만.
- **수수한 초보 모험가 / 길드 잡일 신입**: 무도복·어깨 폴드런 제거 ← bm 피드백. 대신 **여행자 튜닉(오트밀 탄) + 갈색 조끼**(가슴 V로 열리고 허리 아래 닫혀 멜빵 아닌 조끼로 읽힘) + 벨트 + **작은 심부름 파우치**(잡일 소품 1점). **rust 네커치프**(시그니처 색)를 얼굴 곁에 둬 따뜻함.
- **백스토리 무드(외형에만 은은히, 대사/문서 노출 X)**: 과거 주인공 아버지에게 구출돼 길드에 들어온 신입 — 수수한 차림 + 우직한 충성의 따뜻한 인상으로 반영.
- **밝은 덜렁이 + 충성·따뜻함**: 크고 밝은 **호박색 눈** + 큰 캐치라이트 + 입꼬리 올라간 **활짝 열린 미소 + 덧니** + 은은한 홍조.
- **톤 가드**: RLD 어두운 던전 채도와 어우러지게 — 고채도 X, 브래스 1점(파우치 클래스프)뿐. 레플리(하늘색)·리카(데님) 사이에서 **따뜻한 갈색/탄/rust** 로 색 대비 확보.

## 이식 참고 (Claude Code)

- **추가 위치**: `web/js/game/opening-art.js` 에 `drawQkunPortrait` export 추가(레플리/리카 옆). 시그니처·골격 동일하므로 그대로 드롭인.
- **무대 배선**: `main.js:_drawGuildScene` 의 firstclear 비트에서 레플리/리카와 동일 호출 패턴으로 퀴니 슬롯 배치(같은 baseY 라인·scale·광원).
- **미리보기 이식(권장, §5-2)**: `web/_npc-preview.html` 에 퀴니 슬롯 추가 — web/ 영역이므로 여기선 손대지 않음. 이 폴더 미리보기가 그 레이아웃의 참조.
- 색 토큰은 함수 상단에 모여 있으니 bm 레퍼런스 확정 후 톤 미세조정은 토큰만 만지면 됨.

## 변경 이력

- **v1**: 크림 무도복(gi) + 어깨 가죽 폴드런 + 높고 뾰족한 귀 + 옆 포니테일. → bm: "다람쥐로 읽힘 / 무도복 불필요".
- **v2 (현재)**: 늘어진 개 귀 + 슬림 꼬리 + 옆 포니테일 제거 + 초보 모험가 차림(튜닉+조끼+파우치) + 백스토리 무드. 골격·눈높이·색토큰 방식은 v1 유지.

## 열린 것 (bm 입력 대기)

- **컨셉 레퍼런스 미확정**: 브리프 §3(히타무 키얀 "느낌" 오리지널) 기준 제안. bm 레퍼런스 확정 시 함수 상단 색 토큰 + 귀/표정만 만져 빠르게 수렴.
- 조정 후보: 귀 처짐/접힘 정도, 표정 강도(활짝 ↔ 차분), 튜닉/조끼 색조, 파우치 위치(+x ↔ 중앙).
