# 의뢰 보드 & 대기실 — 설계 스펙

> 길드에서 던전에 도전하는 모든 통로를 **하나의 흐름**으로 일원화한 UI 스펙.
> 현재 구현(목업) + 해금 후 등장할 기능 + 미결 모델을 함께 박제. 후속 에이전트/디자인 핸드오프용.
> 카피·비주얼은 전부 자리표시자 — 실제 디자인은 이 구조를 스펙 삼아 별도 진행.

*Last updated: 2026-06-04*

---

## 0. 한 줄

의뢰판(씬 오브젝트) 클릭 → **의뢰 보드**(모니터 겸 선택) → 미션 카드 클릭 → **대기실**(그 던전 한 곳의 통제판) → 출발 → 플레이.
"나가서 지휘소/창고 따로 가기" 없이 보드+대기실에 흡수한다.

---

## 1. 진행 구조 (챕터)

- **챕터 간 = 순차 해금** (선형 척추 — 알고리즘/RL 개념 도입 순서 보존, §11).
- **Ch.1 = 튜토리얼, 무조건 순차** (자율 안 줌 — 순서 지키려 챕터 잘게 쪼개는 것 방지).
- **Ch.2부터 = 챕터 *내* 자율 순서** (그 챕터 일반 의뢰를 자유 순서로 도전).
  - ※ 현재 코드는 던전별 선형 해금. "챕터 단위 해금"은 후속 구조 작업.
- **챕터 구성** = 일반 의뢰(쉬움/중간) 여럿 + **보스 1**. 일반 의뢰 모두 답파 시 보스 해금 → 보스 클리어 = 챕터 완료 → 다음 챕터.
  - **보스 = 캡스톤 던전**(전투 아님 — RLD엔 전투 없음). 각 챕터 `dungeons[]`의 마지막을 보스로 지정. **새 던전 추가 X**(§15).
  - 보스 게이트 = `해당 챕터 일반 던전 전부 clearedDungeons` (현재 코드로 계산 가능).

### HUD (간판)
- 좌상단 `Serpa Guild` + 진행도 `Ch.N 챕터명 · K 답파`.
- **Run#(도전 횟수) HUD에서 제외.** 도전/사망/총스텝은 엔딩 기록(§10)으로. 답파 수 마일스톤 = 이벤트 훅(후속).
- 식량·HP는 길드 HUD에서 숨김 (식량=라운드/출정 자원, HP=인-던전).

## 2. 의뢰 보드 (모니터 겸 선택)

- **챕터 네비**: `‹ Ch.N 챕터명 ›` — 도달한 챕터(1..현재)만 이동. 과거 챕터로 가서 파밍 가능. 미래 챕터 숨김.
- **미션 카드**: 현재 보는 챕터의 *해금/답파된* 일반 의뢰만. 잠긴 미래는 숨김(또는 "다음 의뢰는 답파 후 열립니다").
- **보스 슬롯**: 일반 의뢰 다 답파 전엔 잠김 표시, 후엔 보스 카드.
- **모니터링 = 카드 상태 그 자체** (별도 지휘소 방 없음). 누가 어디서 자동 도전/파밍 중인지 카드가 보여준다.

### 미션 카드 상태표
| 상태 | 표시 | 클릭 |
|---|---|---|
| 도전 가능 | `NEW` + 난이도★/보상/한줄힌트 | ✅ 대기실 |
| 답파(파밍 가능) | `CLEAR` + 반복 보상 | ✅ 대기실(파밍) |
| 도전 중(세르파 자동) | 🔒 `{세르파} 학습 · NN%` | ❌ (후속) |
| 파밍 중(세르파 점유) | 🔒 `{세르파} 파밍 · 답파율 100%` | ❌ (후속) |
| 보스 잠김 | 🔒 `이 챕터 의뢰 모두 답파 시 열림` | ❌→해금 |
| 미해금 | 숨김 / `???` | — |

- 난이도 = ★ 티어 (챕터 기반: ch≤2 ★☆☆ / ch≤4 ★★☆ / else ★★★).
- 한줄 힌트 = **무료 플레이버**(비유적·단편적, 예 "위험한 녀석이 도사린다"). 구체 정보는 대기실의 **유료 정보 구매**(§4.2)와 2단.

## 3. 대기실 (per-dungeon 통제판 — 상태 따라 변신)

같은 면이 그 던전의 상태에 따라 모습을 바꾼다. **탭으로 나누지 않는다.**

| 던전 상태 | 대기실이 보여주는 것 |
|---|---|
| 미답파 · 파티장 직접 | **출정 준비** (현재 목업): 미니맵 · 정보 · 식량 · 출발 |
| 미답파 · 세르파 파견 | **세르파 진행 모니터링 UI** (도전중 진행률·회수) — 후속 |
| 답파 완료 | **파밍 UI** (경로 기반 반복 수입·세르파 배치) — 후속 |

### 구성 요소
- **미니맵**: 현재 밝혀진 만큼. **단순 플랫셀 렌더**(인게임 텍스처 필드와 다름). **첫 던전은 제공**(튜토리얼 예외). 일반 규칙은 탐사로 안개 해제 → 미답파 던전은 거의 빈 상태가 정상(미니맵은 답파/파밍 던전에서 빛남).
- **정보줄(적응형)**: 난이도★ + 답파 여부. 답파 후: 답파율·지도%·최단보·도전횟수(데이터는 후속). 미답파면 `난이도 · 미답파`만.
- **힌트 2단**: 무료 플레이버 + 유료 정보 구매(§4.2, 후속 경제).
- **출정 방식 토글**: `(파티장 직접) (세르파 파견)`. **세르파 0명인 튜토리얼에선 토글 자체 숨김** — 행동은 [출발] 하나(암묵적 직접). 첫 세르파 합류 시 토글 등장 + 도입 비트.
  - 세르파 파견 클릭 → 하단에 *출격 가능 세르파 명단* 펼침(탭 아님). 선택 → 파견.
- **보급**: 식량 스테퍼 `[−] N [+]` (1G/개). **배낭**(일회용 아이템 장착) = 출발/뒤로 위 버튼 → 인벤토리 팝업. *안 써도 갖고 들어가면 소모.* → **기획만, 현재 UI 미포함.**
- **하단 고정**: `[취소]` `[출발 ▶]` — 탭/모드와 무관하게 항상 하단. 어느 상태에서도 여기서 출발.

### 출발(deploy)
- 길드 팝업 닫고 → `loadDungeon` → 플레이 화면(screen-dev) 전환 → `tryEnterDungeon`. (출발 시에만 플레이 화면으로.)
- ※ 실제 플레이 화면은 아직 dev 워크벤치 — 클린 플레이 화면은 별도 후속.

## 4. 자원 / 아이템 / 장소

- **식량 = 인스턴트·휘발 자원**: 출정 시 G로 보급(1G/개), 남으면 전량 소멸. **인벤토리에 안 쌓임. 매대에서 안 팖.**
  - ⚠️ **모델 갭**: 코드의 `runState.food`는 런 사이 persist. "휘발(매 출정 새 보급)" 전환은 후속 (DEATH_LIMIT 갭과 동류).
- **아이템 = 현재 일회용 위주.** 배낭(이번 출정 장착, 대기실) + 획득은 후속. **창고(전체 재고 방)는 보류** — 비소모/장비가 생길 때 값을 함.
- **상점(매대)**: 식량 비매품 + 아이템 보류라 **현재 팔 게 없음 → 구현 대상 아님.**

### 길드 씬 오브젝트 매핑
```
의뢰판  → 의뢰 보드 → 대기실   (도전 통로 일원화: 출정·모니터·회수·파밍 전부)
데스크  → 세르파 명단 (보유/고용/육성 — 도전과 다른 축, 유지)
매대    → 상점 (보류)
벽지도  → 지도/탐사 현황 (or 보드에 흡수 검토)
지휘소·창고 = 별도 방 안 만듦 (보드·대기실·상점에 흡수)
```

## 5. 튜토리얼 점진 노출 원칙

지금 쓸 수 없는 UI는 **숨긴다**(잠긴 버튼도 X). 해금되며 등장 + 도입 비트.
- 튜토리얼 대기실에 *없음*: 출정 방식 토글, 세르파 명단, 배낭, 상점, 정보 구매.
- *있음*: 미니맵, 정보줄(난이도·미답파), 식량 스테퍼, 입장료/보유/보상, 취소/출발.

## 6. 현재 구현(목업) 상태 — 2026-06-04

- ✅ 의뢰 보드: 챕터 네비 + 미션 카드(NEW/CLEAR/파밍중 틀) + 보스 슬롯(게이트). 풀-페이지.
- ✅ 대기실: 정보줄(적응형) + 식량 스테퍼 + 출발/취소. **(이번 트리밍으로 탭/토글/배낭 제거 + 단순 미니맵 추가 예정)**
- ⏳ 후속: 세르파 파견·진행 모니터링·파밍 UI 변신 / 챕터 단위 해금(자율) / 보스 풀로직 / 지도%·도전횟수 데이터 / 정보 구매 경제 / 배낭·아이템·상점 / 식량 휘발 전환 / 클린 플레이 화면 / 답파 마일스톤 이벤트.
