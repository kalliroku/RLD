## 한 줄 정체성

> **알고리즘이 곧 캐릭터인 시드 기반 로그라이크 — 매 런 다른 모디파이어 아래 한정된 세르파 풀로 던전을 답파한다. RL 교육은 부산물.**

D-4 verdict §"한 줄 정체성" 그대로. 마케팅 카피·README·GDD·devlog 모두 이 문장에서 파생되어야 함. 다른 문장과 공존 불가.

## 2. 세션 / 게임 길이

## 6. 플레이어 여정 (목표 경험)

### 첫 5분
1. 웹 페이지 진입. 우측 컨트롤은 4개 섹션만 (Character / Dungeon / Reset / Legend) — **Step-0 모드** (B-004).
2. 캔버스 위 inline hint: *"방향키 / WASD 로 사르사를 움직여 녹색 G 에 도달."*
3. 던전 1 클리어 → 클리어 토스트.
4. **첫 클리어 직후** AI Training 패널이 "NEW" 배지로 펼침 + 토스트: *"이제 AI 에게 길을 외우게 시켜보세요."*
5. 사르사를 던지면 학습 시작. **Q-value 히트맵 + sparkline 디폴트 ON** 으로 학습이 *눈에 보인다*.

### 첫 런 끝 (~30~45분)
- Ch.1 ~ Ch.2 완료. 세르파 4~5명 보유. 골드 ~1000G.
- 다음 던전 입장료 부족 → 런 종료 화면: *"이번 런 던전 6개 답파 / 세르파 사망 0 / 진행도 18%."* **"다음 런"** 버튼.

### 5번째 런
- 게임 상단 모디파이어 띠: ***"이번 런: 미끄러운 바닥."***
- 사르사가 헛도는 모습 (slippery transition 으로 Q-table 정렬 안 됨). 플레이어가 *다이나-Q* 로 교체 (모델 기반이라 빠른 재계획).
- 후반 챕터 도달. 세르파 1 사망. 누적 한도 (예: 4회) 까지 3 남음. 텐션 발생.

### 첫 1.0 캠페인 클리어 (6~10시간 누적)
- Ch.7 답파 → 엔딩.
- NG+ 진입: 모디파이어 풀 확장 (12종 → 18종) + 강도 상향 (복합 시드: "미끄러운 바닥 + 안개 짙음" 동시).

### 데일리 시드 (10분/일)
- 같은 날 모든 플레이어가 동일 시드 + 모디파이어.
- "어제 +3 던전" 같은 자기 비교. 백엔드 없이 로컬 "오늘의 기록" 저장.
- (출시 후) 리더보드 도입 검토 — 수요 측정 후.

- itch.io 다운로드 **1,000+**
