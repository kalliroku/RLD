# Advocate B — "RL 양념" 노선

## 입장 요약 (3~4줄)

RL 은 **양념**이지 주재료가 아닙니다. 알고리즘은 캐릭터 개성의 출처일 뿐이고, 게임의 코어 동사는 "**시드 기반 로그라이크 답파**"여야 합니다. 시뮬레이터가 발견한 "수동 100배 저렴"은 고칠 버그가 아니라 **인정해야 할 진실**이며, RL 주재료 포지셔닝은 어떤 청중에게도 깊게 핏하지 않는 죽은 노선입니다. 한 줄: "**알고리즘이 곧 캐릭터인 시드 기반 로그라이크 — 매 런 다른 모디파이어 아래 한정된 세르파 풀로 던전을 답파한다.**"

## Position A 반박 (상대 최강 주장 + 가장 약한 주장 정면 공격)

**A 의 최강 주장 — "이코노미 외과 수술" 신화에 대한 반박:**

A 는 "운영비 -50~70%, 식량 +N배"면 RL 이 정공법으로 돌아온다고 주장합니다. 숫자 조정으로 RL 을 강제할 수는 있습니다. 그러나 *그 다음에 플레이어가 실제로 하는 행위*가 무엇인지를 묻지 않았습니다. **답: "AI 가 30분간 같은 던전을 1만 에피소드 도는 걸 관찰"**. 이건 재미가 아니라 고역입니다. 게임 디자이너 크리틱조차 "학습 대기 시간이 지루"하다는 GDD §9.2 리스크를 그대로 짊어지고 있을 뿐, 해결책이 없습니다. AI Training Visualization 이 1x/2x/3x/Instant 4단계로 만들어진 이유 자체가 *"보다가 지쳐서 Instant 누르게 된다"*는 사실의 자백입니다. 학습 관찰의 엔터테인먼트 한계는 명확합니다 — 트레일러로 30초는 멋있고, 게임플레이 동사로 8시간은 불가능. Twitch 에서 AI 학습 스트리밍이 long-form 콘텐츠로 성립한 사례는 0건이고, Two Minute Papers 가 *2분짜리*인 데에는 이유가 있습니다.

또한 이코노미 수술은 시뮬레이터의 4전략 결과를 **부정**하는 일입니다. HybridPlayer 가 29.5/31 로 1위인 건 우연이 아니라 *플레이어 두뇌가 BFS + HP 휴리스틱을 RL 보다 1000배 빠르게 푸는 본질적 비대칭*. 이걸 페널티로 막으면 플레이어는 "올바른 동작이 막혔다"고 느낍니다 — 정공법이 아니라 *우회로를 봉쇄당한 감옥*입니다.

**A 의 가장 약한 주장 — "마스터리 = 하이퍼파라미터 튜닝" 직격:**

A 의 retention 답안 후보 중 (i) "하이퍼파라미터 슬라이더 + 리더보드"는 **fun loop 가 아닙니다**. 일반 플레이어가 lr=0.1 vs 0.05, γ=0.9 vs 0.99, ε-decay 0.995 vs 0.999 슬라이더를 만지는 게 즐거움인가? 이건 *수치 sweep 노가다*이지 게임이 아닙니다. ML 엔지니어조차 자기 일에서 hyperparameter sweep 을 가장 싫어합니다 — 그래서 Optuna 와 W&B sweeps 가 존재. RLD 가 그 노가다를 *콘텐츠로 포장*하면 ML 직장인은 도망가고 일반 플레이어는 의미를 못 읽습니다. 마스터리 노선은 (ii) "**시드 챌린지 + PCG**" 하나로 좁혀야 하며, 이는 본 입장(RL 양념)과 정합합니다.

## 본 입장 강화 — 시드/모디파이어 시스템 구체 설계

이미 가진 자산: 15개 세르파 + 31개 던전 + Lv.30~31 BSP+CA 절차적 생성기 + 시드 고정 재현. 이걸 *회전*시키면 됩니다.

**모디파이어 룰 포맷**:
```
Run Modifier = { id, scope: 'global'|'sherpa'|'dungeon', effect: <delta>, narrative }
```

**예시 7종 (난이도 ↑/특이성):**

1. **"미끄러지는 바닥"** — global, 모든 빈 타일이 30% 확률로 의도와 다른 방향으로 미끄러짐. (Lv.26~28 의 Slippery 메커니즘 전체 던전 확장)
2. **"두 명만"** — sherpa, 이번 런은 무료 3인 중 2명만 고용 가능. 어느 알고리즘 페어로 갈지 강요됨.
3. **"안개 짙음"** — global, 시야 반경 -1. Local 관측 알고리즘(스카우트류 부활) 가치 급등.
4. **"인색한 길드"** — global, 첫 클리어 보상 -40%, 반복 파밍 +60%. 답파보다 파밍 비중 강제.
5. **"몬스터의 밤"** — dungeon, 무작위 던전 5개에 몬스터 +50% 증식, 클리어 시 추가 50G.
6. **"트레저 헌트"** — dungeon, 무작위 던전 3개에 보물 +2. HP-aware 라우팅 가치 폭증.
7. **"의심의 안개"** — sherpa, 사르사·더블Q·QV군에게만 보너스 +10G/clear (Off-policy 응징).

**일일 챌린지 케이던스**:
- **Daily Seed** (24h): 모든 플레이어 동일 시드 + 동일 모디파이어 3개 조합. 리더보드 (스텝 / 골드 / 사망 수).
- **Weekly Gauntlet** (7d): 모디파이어 5개 + 절차적 던전 강제 (Lv.30~31 + 신규 5개 PCG 슬롯).
- **Free Seed**: 플레이어가 직접 입력해서 친구와 공유.

**PCG 자산 재활용**: `dungeon-generator.js`의 BSP+CA 파이프라인을 31개 고정 던전 *위에* 얹어 (a) tile-swap 변형 (Trap↔Heal swap, 골드 재배치), (b) 부분 영역 regenerate (50×50 의 사분면 1개만 재생성), (c) 시드별 시작/목표 회전. 새 던전 만들지 않고도 사실상 무한 변주.

**시드가 가져다주는 의외성의 메커니즘**: 시드 기반 PCG 는 *플레이어 모르게* 룰을 흔드는 것이 아닌, *룰은 동일하되 지형이 흔들리는* 형태. 따라서 BFS 휴리스틱은 매 런 새로 짜야 하고, 외운 Q-table 은 부분 가치만. 이게 RL 의 캐릭터 차이가 *비로소* 보이는 지점입니다 — Q군(좌표 암기형)은 시드 흔들리면 무력, 다이나/스위퍼(모델 기반)는 빠르게 재계획, 트레이서(eligibility trace)는 변경된 경로 누적학습.

## 본 입장 강화 — 알고리즘 = 캐릭터 메커니즘

알고리즘을 *학습 대상*이 아니라 *캐릭터 시그니처*로 격하하면 GDD 의 모든 데드락이 풀립니다. 세르파의 성격("낙관적 멍청이", "겁쟁이", "공상가", "효율주의자")이 곧 알고리즘의 게임플레이 표현이고, 플레이어는 알고리즘 이름을 몰라도 "*아, 사르사는 절벽 옆을 피하고 Q군은 들이댄다*"를 체감으로 학습합니다. 이건 교육이 아니라 **캐릭터 빌딩**이며, 부산물로 RL 직관이 따라옵니다.

## 시장 사례 (StS / Hades / Balatro / RoR 등)

- **Slay the Spire**: 4개 캐릭터가 "데크 빌드 동사"로 완전히 다른 게임이 됨. Ironclad(체력/공격), Silent(독/덱순환), Defect(오브), Watcher(자세). 메커니즘이 캐릭터.
- **Hades**: Zagreus 는 하나지만 6개 무기 aspect 가 사실상 다른 캐릭터. Aspect of Guan Yu(피 흡혈), Aspect of Lucifer(빔). 동일 입력이 6배의 게임으로 분기.
- **Balatro**: 150+ 조커 카드 각각이 "이 런의 정체성". 알고리즘 카탈로그처럼 보이지만 플레이어는 수학을 의식하지 않고 *시너지*만 느낌.
- **Risk of Rain 2**: 아이템 stack 의 곱연산 효과가 빌드 동사를 형성. 플레이어는 "이번 런은 Backup Mags + Ukulele 빌드"라고 부름.

**작동 메커니즘**: 위 사례의 공통점은 *메커니즘이 곧 캐릭터/빌드의 정체성*이라는 것. RLD 의 15개 알고리즘은 이미 같은 잠재력을 가지고 있습니다 — Q-Learning 의 낙관성, SARSA 의 보수성, Dyna-Q 의 상상력, n-step 의 선견성. 이걸 *논문 인용*이 아니라 *플레이 시그니처*로 노출하면, RLD 는 StS 의 캐릭터 다양성을 RL 로 재해석한 게임이 됩니다.

## 자기 약점 인정 (1단락)

이 노선의 약점: "AI 가 던전을 학습한다"는 RLD 가 가진 *진짜 마케팅 훅*을 트레일러 30초 분량으로 압축시키게 됩니다. AI 호기심 일반인 세그먼트가 "이거 RL 게임이라며?"하고 켰을 때 "사실은 로그라이크고 RL 은 캐릭터 양념"이라는 사실에 실망할 가능성이 있습니다. 또한 시드/모디파이어 시스템 구축에 PCG 확장 공수가 추가로 들고, 31개 던전을 시드 변주로 재활용하는 작업은 *밸런스 회귀 테스트*가 다시 한 바퀴 필요합니다. 그러나 이 비용은 *재방문 루프 없음*이라는 치명상보다 압도적으로 작으며, RL 주재료 노선이 약속하는 미래(AI 학습이 정공법인 게임)는 학습 관찰의 엔터테인먼트 한계 때문에 도달 불가능한 신기루입니다.
