## RLD UX 비판 검토 (4축)

### 1. 첫 5분 경험 — **가장 큰 약점**

**(a)** 첫 화면에서 신규 플레이어는 동시에 본다: 15개 캐릭터 카드, 31개 던전맵, AI Training 패널, Provisions(식량 구매), Stats, Visualization 토글, Game Mode 토글. "키보드로 직접 플레이하는 게임"인지 "AI 학습 도구"인지 즉시 분간 안 됨. Welcome tutorial-tip은 "방향키로 녹색 골에 도달"이라 잘 시작하지만, 화면 우측에 이미 "AI Training / Until Success / Continuous / Instant" 등 의미를 모르는 단어가 노출돼 인지 부하를 끌어올림.

**(b)** **Step-0 모드 분리**: 첫 진입 시 우측 컨트롤 컬럼 전체를 접고, Character / Dungeon / Reset / Legend만 노출. AI Training, Provisions, Stats, Farming, Visualization은 첫 클리어 또는 첫 5번 사망 이후 "NEW" 배지로 한꺼번에 펼침. ACT1 폴리시의 progressive disclosure 룰을 더 공격적으로(현재는 Ch.2 이후/farm 후 두 시점뿐). HTML 정적으로 박힌 캐릭터 카드 15개도 챕터 합류 전엔 `dm-locked` 스타일과 동일한 "??? / 잠김" 슬롯으로 렌더링. 공수: **2~3일**.

**(c)** 푸터의 "Arrow keys to move | R to reset | Reach the green goal!" 한 줄을 캔버스 위 inline hint로 끌어올려 첫 5초 안에 시야에 들어오게.

### 2. 정보 과부하

**(a)** 캐릭터 카드에 "Q-Learning, SARSA, Monte Carlo, SARSA(λ), Dyna-Q, REINFORCE, Actor-Critic, Local Q, QV-Learning, ACLA, Ensemble, Exp SARSA, Double Q, Tree Backup, Pri. Sweep"가 그대로 라벨. 비전공자에게는 무의미한 학명. 동시에 한국어 캐릭터명(사르사/몬테/트레이서…) + 영어 메뉴(Run, Gold, HP, Reward, Until Success…) 코드 스위칭.

**(b)** 카드 알고리즘 라벨을 **성격 태그로 1차 교체**, 알고리즘 명은 hover/long-press 툴팁으로. ACT1_SUMMARY에 이미 정의된 성격("낙관적 멍청이", "겁쟁이", "공상가" 등) 활용. 우측 컨트롤 섹션 헤더도 한국어 통일 ("AI Training" → "훈련", "Provisions" → "보급"). 공수: **반나절** (CSS + 라벨 데이터만).

### 3. 시각 피드백

**(a)** Q-Value 히트맵의 숫자 텍스트는 `tileSize × 0.22`라 25×25/50×50 던전에서 글자가 ~7px 이하로 떨어져 읽을 수 없음. 히트맵과 정책 화살표를 동시에 켜면 흰 화살표 + 흰 Q수치 + 빨녹 배경 + 안개 오버레이가 한 셀에 겹침. PIT 셀("X" + 어두운 회색)과 fog 셀(어두운 #0a0a0f + "?")이 모두 검정 계열이라 구분이 약함. 디폴트에서 두 토글이 OFF라 신규 플레이어는 학습되는 느낌을 못 받음.

**(b)** ① Q-Value 시각화는 **숫자 제거하고 색만**, 셀이 작아지면 자동으로 단순화. ② "Show Q-Values" 디폴트 ON으로 변경하고 토글 옆에 작은 미리보기 아이콘. ③ PIT는 빨간 X / fog는 회색 ?로 색 분리. ④ Training 중에는 캔버스 하단에 "Success rate ↑" 미니 sparkline을 1줄로 상시 표시 — 토스트보다 학습 진행감이 강함. 공수: **1~2일**.

### 4. 모바일

**(a)** 50×50 던전 = 2400px 캔버스 → 모바일 가로 스크롤 필수. 우측 control 10+ 섹션이 세로로 늘어져 캔버스 보려면 스크롤 한참. HP bar의 flex stats가 좁은 화면에서 줄바꿈으로 무너짐. 토스트 컨테이너가 캔버스 위에 떠 작은 화면에서 게임 화면 잠식.

**(b)** ① 캔버스 `max-width: 100vw` + 자동 fit-to-screen (큰 던전은 미니맵 띄움). ② 모바일에서 우측 컬럼을 캔버스 하단 탭 바(Char / Dungeon / Train / Shop / Stats 5탭)로 재배치. ③ 스탯은 모바일에서 핵심 3개(HP / Gold / Steps)만 노출, 나머지는 접힘. 공수: **3~4일** (캔버스 fit이 가장 무거움).
