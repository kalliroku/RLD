## RLD "누구를 위한 게임이고 왜 다시 켜는가" 5축 비판

### 1. 타겟 페르소나 — 누구도 1순위 아님

GDD 가 명시한 타겟(RL 입문자/학생/메이커 팬)은 **현실에서 한 명도 깊게 핏하지 않습니다**.
- CS 학생: 31개 던전을 클리어하느니 Sutton & Barto 챕터를 풀 동기가 큼. RL 학습용으론 너무 게임적, 게임용으론 너무 RL 적.
- 로그라이크 팬 (StS/Hades): 음식·런·해금 골격은 있지만 **빌드 다양성, 시너지, 의외성**이 0. 31개 던전은 "스테이지" 일 뿐 빌드와 무관.
- 인디 호기심층: 알고리즘 이름(아클라/트리백) 진입장벽이 살벌함.
- AI 호기심 일반인: PPO 정직성 입장 때문에 마케팅 훅이 없음.
- (a) 잃는 세그먼트: **전부 절반씩만 잡고 있음.** (b) **로그라이크 팬으로 좁히고 RL 은 "캐릭터 개성의 출처"로만 격하**시키는 게 가장 현실적 피벗. (c) 중공수.

### 2. 재방문 루프 — Day 2 훅 없음

devlog E-1 의 시뮬레이터 결과가 결정적입니다: **HybridPlayer 가 368턴에 29.5/31 클리어**. 즉 한 런이 사실상 게임 클리어. NG+ 는 "Q-table 유지" 라는 RL 인사이더용 보상이라 일반 플레이어에겐 무의미. 콘텐츠 추가(던전/알고리즘)는 **선형 인플레이션**이지 루프가 아님 — 31번째 던전이 1번째보다 더 재밌게 만드는 시스템이 없음.
- (a) 잃음: 로그라이크 팬 (StS 는 매 런이 새 빌드, RLD 는 매 런이 같은 스크립트).
- (b) **시드/모디파이어 시스템**: 매 런마다 던전 일부를 절차적으로 변형(이미 Lv.30~31 생성기 존재), 세르파에 매 런 다른 perk/구속 부여. **"이번 런은 사르사로 미끄러운 던전만"** 같은 모디파이어가 retention 의 본질.
- (c) 중공수, 단 절차적 생성기 자산을 재활용하면 절감.

### 3. 숙련 곡선 — 마스터리 정의 없음

"잘하게 된다"의 정의가 없습니다. 직접 플레이는 BFS 면 끝, RL 튜닝은 UI 노출 0 (`createAlgorithm` 하드코딩), 던전 설계는 평가 시스템 없음 (BFS 검증뿐, 다른 플레이어에게 풀려주는 루프가 Act 2 미구현).
- (a) 잃음: 고관여 플레이어 전체.
- (b) **하나만 선택**: (i) **하이퍼파라미터 슬라이더 + 리더보드** (학습형), (ii) **던전 갈수록 PCG + 시드 챌린지** (로그라이크형), (iii) **던전 만들어 비동기 PvP** (메이커형). 셋 다 노리는 현 상태가 "각각 1/3 수준"의 원인.
- (c) 옵션마다 다름; (ii) 가 기존 자산 재활용도 최고.

### 4. NPC 가차 (Phase 16) — 가차로 결함을 덮으려는 신호

위험합니다. **재방문 결함을 가차 가렴(pity)으로 메우려는 패턴**. NPC = 알고리즘이라 "삭(SAC) 뽑았는데 SAC 적합 던전이 없으면 무용지물" → 가차 보상 가치가 던전 콘텐츠에 종속됨. 또한 PPO 를 "좁은 일반화"로 정직하게 인정하는 작성자 철학과 "레전더리 SAC = 모든 스탯 +15%" 카드 마케팅이 **충돌**.
- (a) 잃음: 솔직성에 끌린 코어층 + 가차에 익숙한 캐주얼층 동시에.
- (b) **가차 폐기**, 대신 NPC 를 **언락 진행**(현재 고용 시스템 강화) 으로. 가차 만들 공수를 modifier/PCG 에 투자.
- (c) **가차 만들면 대공수, 폐기는 무공수 + 기회비용 회수**.
