## 등장인물 / 진영

### 길드장 (유저)
플레이어 시점. 세르파 길드 *2대 길드장*. 아빠와 함께 던전에 잠입했다가 *귀환 아이템* 으로 혼자 빠져나옴. 트라우마로 오랜 기간 길드를 방치. 어떤 계기 (돈 / 아빠 단서 / 모험가 길드의 부추김) 로 다시 던전에 진입 — 이게 게임 시작 시점.

**고유 자산**: 아빠가 남긴 *부활 아이템*. 길드장이 보유 + 발동. 세르파들이 던전에서 사망 시 **무제한 부활** — 단 부활마다 **G(골드) 소모**. 이게 RLD 정체성 "무한 도전으로 답파"(= RL 무한 에피소드 반복)의 서사화. **G = 0 → 파산 엔딩**(캠페인 리셋). (D-2026-06-02-18 — 기존 "누적 사망 4/4 충전 한도 / B-203"를 무한부활+G소모로 갱신, 🔁 supersede.)

처음에는 *모험가 길드의 도구* 임을 모름. 게임 진행 중 어느 시점 *이용당함* 을 깨달음 (진실 폭로 시점은 W7.4 결정 영역).

### 아빠
선대 영웅. 던전 답파의 전설. **세르파 길드 창립자** (모험가 길드의 던전 독점에 반발해서 창립).

아들과 던전 잠입 → 아들에게 귀환 아이템 사용 → 본인은 던전에 남음 (실종으로 알려짐). **실제로는 살아있음** — 던전의 *모더(modder)* 가 되어 모험가 길드에 복수하려고 매번 다른 시련을 박음.

**게임 시스템 흡수**: **모디파이어 12종** (D-2026-05-14-14, slippery / heavy_fog / poison_floor / mirror_input 등) = 아빠가 박은 시련. 데일리 모디파이어 = 아빠의 *매일 시련*.

### 모험가 길드 (흑막)
기존 던전 답파 권리 + 이권 독점 시도. 위험을 감수하기 싫어함. 신규 도전자 진입 차단. 세르파 길드 존립은 *조롱/이용* 차원에서 인정 — "모험가가 되지 못한 못난이들" 을 세르파 길드로 흘려보내 구조를 확고히 함.

**부추김 동기**: 아빠가 아들을 탈출시키면서 *뭔가 남겼을 거라는 추측*. 그것 (= 부활 아이템) 을 빼앗아 세르파 길드를 무력화하려는 의도. 유저를 던전에 들여보내 *위치 + 아이템 확인*.

**game-internal 흡수**: shop 탭의 *모험가 도움 (W7.4 신규 시스템)* 이 그들의 손길. **manual play (길드장 직접 진입) 시 모험가 동반하면 즉시 베드 엔딩** (위치 노출 → 살해 → 부활 아이템 약탈). AI 학습 시 동반은 안전 (길드장 부재).

### 세르파 길드 (주인공 측 / 신흥세력)
아빠가 창립한 비-기득권 진영. 모험가 길드의 압박 하에 명맥 유지. 아빠 실종 후 유저가 (의도와 무관하게) 길드장 자리에 앉음.

### 세르파 (영입 캐릭터들)
**모험가가 되지 못한 낙오자들**. 본인은 부활 능력 X. 길드장의 부활 아이템에 의존해 던전에 들어감. 각자 다른 *사고방식* 으로 던전을 풀려고 시도.

**game-internal 흡수**: 캐릭터 카드 = 세르파들. 학명 (Q-Learning / SARSA / Monte Carlo / Dyna-Q / ...) 은 *캐릭터 hover 툴팁만* (B-105) 노출 — 표면은 "신중한 학습자" / "즉흥적 도전자" 같은 *성격 태그*. **알고리즘=캐릭터 비유는 narrative 안에 흡수, RL 학명은 opt-in**.

## 사건 흐름

### 과거 (게임 시작 전)
1. 아빠 = 그 시대 영웅. 던전 답파의 전설.
2. 모험가 길드가 던전 이권 독점 시도. 도전자 진입 차단.
3. 아빠가 반발 — 세르파 길드 창립. 모험가 못난이들을 모아 던전 답파 가능한 *대안 진영* 구축.
4. 부활 아이템 확보 (출처는 미정 — 던전 깊은 곳에서? 아빠의 발명? 별 사이클 결정).
5. 아빠와 아들 (유저) 던전 잠입 — 특수한 *모험*. 깊은 곳에서 어떤 사건 발생.
6. 아빠가 귀환 아이템으로 아들을 *탈출* 시킴. 본인은 던전에 남음. *실종으로 알려짐*.

### 현재 (게임 시작 직전)
1. 유저는 길드장 자리를 *이름만* 보유. 트라우마로 던전 외면.
2. 세르파 길드는 모험가 길드의 *조롱* 하에 명맥만 유지. 새 세르파 영입 가능하나 던전 답파는 정체.
3. 모험가 길드가 유저를 *부추김* — "아빠가 너에게 뭔가 남겼을 거다. 던전에 들어가 확인해라." 본심은 그것을 *빼앗기* 위함.

### 게임 시작 — 재진입
유저가 어떤 계기 (돈 / 아빠 단서 / 모험가 길드 부추김) 로 던전 재진입을 결심. 이 시점에 **부활 아이템 활성화** — 세르파들이 던전에서 사망해도 *G 소모하며* 무한 부활. 게임 본편 시작.

### 진행 (게임 본편)
1. 캐릭터 영입 (Hire) — 모험가 못난이들을 세르파로 받아들임.
2. 던전 답파 — 7 챕터 27 던전. 각 던전마다 아빠가 박은 시련 (모디파이어).
3. **G = 0 → 파산 엔딩** (캠페인 리셋). 세르파 부활 + 모험가 길드 상납금(중반~)으로 G 고갈 시. (D-2026-06-02-18 — 기존 "누적 사망 4/4 소진" 폐기, 무한부활 + G=0 단일 트리거로 단순화. 데스스파이럴 루트는 질질 끌림으로 기각.) 길드장 *직접 출정* 실패 시도 처음부터.
4. NG+ = 새 사이클 / 아빠 단서 한 단계 더 (W7.4 결정 영역).
5. 데일리 = 아빠의 *매일 시련* — 캠페인 진행과 격리된 외전 (D-2026-05-12-8).

### 엔딩 분기
- **굿엔딩**: 27 던전 답파 + 베드 엔딩 미발생 → 아빠와 재회 / 모험가 길드 흑막 폭로 / 세르파 길드 정통성 회복 (구체 카피는 W7.5).
- **베드 엔딩**: manual play 시 모험가 동반 → 즉시 살해 + 부활 아이템 약탈 → "X는 살해됐습니다 → 왜? → 아이템 약탈" 카피.
- **파산 엔딩**: G = 0 → 세르파 운영 불가, 길드 도산 → 캠페인 리셋 (D-2026-06-02-18).

## RL 메타 흡수 룰 (카피 작성 시 게이트)

1. **표면 카피에서 학명 노출 회피** — "강화학습", "Q-Learning", "Q-table", "에피소드", "policy", "reward" 등 RL 학술 어휘 사용 금지.
2. **학명은 캐릭터 hover 툴팁 (B-105) 만 opt-in** — 일반 플레이어 미노출 영역.
3. **Q-heatmap / sparkline = 길드장의 옵션** — *세르파의 기억을 들여다보는 도구* 위치. RL 시연 영역 아님.
4. **모든 시스템 카피는 narrative 어휘로 풀어 씀** — "에피소드" → "탐험", "학습 성공률" → "탐험 성공률", "AI 학습" → "세르파 훈련".
5. **D-2026-05-12-4 "RL 교육은 부산물"** — narrative 가 RL 을 *흡수* 해서 RL 교육이 *전면에 안 보이게* 함. 보이는 건 *세르파가 던전을 익혀가는* 과정.

## 미정 영역 (W7.4 사이클 시작 시 결정)

- 모험가 도움 효과 강도 (충분히 매력적이어야 — 안 그러면 베드 엔딩 트리거 없음)
- manual play vs AI 학습 의 명시적 UI 구분 여부
- 진엔딩 조건 (27 던전 답파 + 베드 엔딩 미발생만으로 충분? 또는 NG+ 의존?)
- 흑막 폭로 시점 (Ch.4~5 / 진엔딩 / NG+?)
- NG+ narrative 위치 (새 사이클? 진엔딩 분기?)
- 부활 아이템의 *출처* (던전 깊은 곳? 아빠 발명? 미지의 진영?)
- 게임 시작 *계기* (돈 / 아빠 단서 / 부추김 — 셋 다 암시 vs 한 가지 한정)
- 세르파 부활 G 단가 / 모험가 상납금 액수·주기·도입 챕터 / 식량의 역할 (출정 비용? G와의 관계) — D-2026-06-02-18 경제 루프 밸런싱 시 확정
