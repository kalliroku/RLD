# 퀴니(Q-Learning 세르파) 흉상 인계 — 신규 (Claude Design)

> 작성: Claude Code (통합 담당) · 2026-06-06
> 채널: 비동기 — `design/` 에 절차적 `draw*Portrait` + 미리보기 HTML 산출, Claude Code 가 `web/js/game/opening-art.js` 로 이식.

## 1. 한 줄 요약

내부 키 `qkun`(알고리즘 = **Q-Learning**)의 캐릭터를 **퀴니**로 재설계했습니다 (이름·성격·설명·대사 코드 반영 완료). 퀴니는 플레이어의 **첫 세르파**이자 1관 클리어 후 길드 대사에 등장하는데 **흉상 아트가 아직 없습니다**(레플리/리카만 존재). father/레플리/리카와 같은 절차 캔버스 방식으로 **`drawQkunPortrait` 신규 제작**을 요청합니다.

## 2. 정체성 컨텍스트 (불변)

> 알고리즘이 곧 캐릭터인 시드 기반 로그라이크. 세르파 = RL 알고리즘 의인화. 어둡고 절제된 던전 팔레트.

- **★ RLD 에서 "격"은 금빛·고채도가 아니라 태도 + 온전한 장비에서 나온다** (father bake-off 학습). 밝고 화려한 고채도는 톤을 깬다.
- 퀴니의 게임 메커닉 = Q-Learning(가본 길을 그대로 외움, 던전별 전문가). 성격은 이 "우직하게 다 외움"과 통한다.

## 3. 캐릭터 — 퀴니

- **종족/외형**: 여성 **갈색 강아지 수인**, **인간에 가깝게**(개 귀 + 꼬리 정도, 본체는 인간형). 오키나와 수호견 *시사(シーサー)* 풍의 "지키는 개" 바이브 차용 가능.
- **체형**: 성인(18+). 동안 + **글래머러스/볼륨감 있는 체형** + 튼튼한 **무도가** 골격(부드러움과 단단함 공존).
- **성격(실루엣·표정에 반영)**: 밝고 단순한 **덜렁이**(자주 넘어짐) · 우직한 **충성심**. 백치미 있는 따뜻함.
- **복장**: RLD 길드 모험가/가드 톤(무도가의 활동성 있는 차림). 던전 팔레트와 어우러지게.

### ★ 레퍼런스
- **히타무 키얀** (애니 *부덕의 길드 / 不徳のギルド*) 의 "**비슷한 느낌**" — 갈색 개 수인 소녀, 글래머·덜렁이·충성. **직접 복제 아님**: 같은 아키타입의 **오리지널** 캐릭터를 뽑아 주세요. (raster 레퍼런스는 게임 미반영, 컨셉 전용.)
- 톤 가드: 성인·애니풍이되 **RLD 도트 해상도(scale 6~)에서 절제되게** — 노골적/과도한 성적 강조 X. 절차 도트의 단순화 안에서 캐릭터성(개 수인·볼륨·우직함)이 읽히면 충분.

## 4. 아트 idiom (기존과 호환)

father/레플리/리카와 동일 — `R(x,y,w,h,c)=fillRect`, **`(cx, baseY)` 발밑 기준 + `scale`**. 광원/페이드/딤은 호출부(`_drawGuildScene` main.js)가 처리. 팔레트는 함수 상단 토큰 + `opening-art.js` PAL 만 (raster 색 새로 X). 같은 무대에 레플리/리카와 **나란히 서므로** 기준점·광원 호환 필수.

## 5. ★ 요청

1. **`drawQkunPortrait(ctx, cx, baseY, scale=6)` 신규 작성** — `design/` 에 절차 함수 + 미리보기 HTML. 시그니처·기준점·scale 을 레플리/리카와 동일하게(드롭인). Claude Code 가 `opening-art.js` 에 추가 + `_drawGuildScene` 무대에 퀴니 슬롯 배선 + firstclear 대사에서 등장하도록 이식.
2. 미리보기는 `web/_npc-preview.html` 에 퀴니 슬롯 추가하는 방향(레플리/리카 옆) 권장.

## 6. do / don't

| ✅ DO | ❌ DON'T |
|---|---|
| 갈색 개 수인(귀+꼬리), 인간형 본체 | 동물에 가까운/머리부터 짐승 |
| 글래머 + 무도가의 단단함 공존 | 노골적·과도한 성적 강조 |
| 덜렁이·충성의 밝고 따뜻한 인상 | 차갑거나 무겁게 |
| RLD 어두운 던전 팔레트와 어우러지는 채도 | 다른 게임에서 온 듯한 고채도 |
| 절차 도트 scale 6~ 에서 읽히는 단순화 | 해상도 대비 과한 디테일 / Kiyan 직접 복제 |
| 레플리/리카와 같은 무대 광원·기준점 호환 | 이질적 별도 스타일 |

## 7. 열린 것 (bm 입력 대기)

- **컨셉 레퍼런스 확정**: 히타무 키얀 "느낌" 기준으로 1차 제안 → bm 피드백 루프. (father·레플리·리카와 동일 절차.)
- 퀴니를 firstclear 무대에 실제 등장시킬지(현재 대사만, 흉상 들어오면 무대 슬롯 추가) — 아트 나오면 Claude Code 가 배선.
