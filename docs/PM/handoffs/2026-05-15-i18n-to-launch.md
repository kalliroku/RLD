## 3. i18n 1.0 게이트 후속 (W1/W2/W3 — 출시 직전 회수)

### 3.1 W1 — 객체 사전 ↔ dict 동기 assertion (5분, P2)

다음 작업자가 신규 modifier/character/item/chapter 추가 시 *세 곳에 동시* 갱신 잊으면 사일런트 mojibake (객체 필드 한국어 노출 / dict-en fallback 한국어). 1.0 출시 직전 build-time check 1회 추가 권장:

```js
// web/js/i18n/sync-check.js (예시, 출시 직전 1회 dev 콘솔 실행)
import { MODIFIERS } from '../game/modifiers.js';
import { CHARACTERS } from '../game/game-config.js';
import { ITEMS, CHAPTER_CONFIG } from '../game/run-state.js';
import { DICTS } from './index.js';

const errors = [];
for (const id of Object.keys(MODIFIERS)) {
    for (const lang of ['ko', 'en']) {
        if (!DICTS[lang][`modifier.${id}.name`]) errors.push(`${lang}: modifier.${id}.name`);
        if (!DICTS[lang][`modifier.${id}.desc`]) errors.push(`${lang}: modifier.${id}.desc`);
    }
}
// CHARACTERS personality/desc, ITEMS name/desc, CHAPTER_CONFIG (chapter.N) 동일 패턴
console.assert(errors.length === 0, 'i18n sync errors:', errors);
```

### i18n 호출 cheat sheet (다음 작업자용)

**HTML 정적**:
```html
<h3 data-i18n="section.character">캐릭터</h3>
<input data-i18n-placeholder="placeholder.name">
<button data-i18n-aria-label="lang.toggle.aria_label" data-i18n="lang.toggle">EN</button>
```

**JS 동적**:
```js
import { t } from './i18n/index.js';

el.textContent = t('guild.deaths_format', { cur: 2, max: 4 });
this.showMessage(t('daily.victory_msg', { steps: 42 }), 'success');
```

**ID 기반 동적 lookup** (modifier/character 등):
```js
const name = t(`modifier.${m.id}.name`);
const desc = t(`character.desc.${charId}`);
```

**동적 element 가드**: 토글 시 `applyTranslations(document)` 가 덮어쓰지 않게 *data-i18n 미적용* + 호출처에서 t() 사용 + HTML 에 주석으로 명시.
