## 3. 세계관 (오프닝에 직접 관련된 부분만)

전체는 `docs/PM/STORY.md` 참고. 오프닝에 직접 사용되는 motif:

- **아빠** = 선대 영웅, 세르파 길드 창립자. 던전 답파의 전설.
- **유저 = 길드장 (아들)**. 어린 시절 아빠와 던전 잠입.
- 던전 깊은 곳에서 무언가 일어남 → 아빠가 **귀환 아이템**으로 아들만 탈출시킴.
- 아빠는 던전에 남음 → 실종으로 알려짐 (실제로는 살아있고 던전의 *모더(modder)* 가 됨 — 이건 후반 진실).
- 아들은 트라우마로 오랜 기간 길드 방치. 게임 시작 = 재진입 직전.

핵심 정서: **신뢰 + 약속 + 비극의 전조**. 트라우마의 기원을 플레이어 본인의 체험으로 박는 것이 목표.

## 5. V2 방향 — 튜토리얼-as-opening

오프닝 = 첫 던전 플레이. 코어 메커닉 5개 (이동 / 목표 G / 식량 / 귀환 / 사망의 무게) 를 플레이로 학습하면서, 그 안에 아빠의 작별 narrative 가 자연스럽게 박힘.

### 사용자 (bm) 가 결정한 사항

| # | 영역 | 결정 |
|---|---|---|
| Q1 | 던전 처리 | (b) 던전 2개 — 1번 클리어 후 페이드 → 2번 진입 |
| Q2 | 아빠 NPC 동행 | (c) 옆 1칸 자동 배치 — 길찾기 없이 동행 체감만 |
| Q3 | 시각 톤 | title palette A 연속성 (Darkest Dungeon-ish, 회색 + 어두운 brown) |
| Q4 | narrative 깊이 | 미니멀 — 대사 최소화, 분위기 위주 |
| Q5 | Page 7 (가운데 씬) | 텍스트만 — 검은 화면 + 글자 |

### 8 단계 시퀀스

| # | 단계 | 학습 / narrative |
|---|---|---|
| 1 | 검은 화면 → 동굴 입구 (1.4초 자동 페이드) | 진입의 무게 |
| 2 | 첫 던전 — 아빠와 같이 몇 걸음 이동 | 이동 학습 (방향키 / WASD) |
| 3 | 출구 G 도달 → 클리어 메시지 → 페이드 | 목표 학습 (G = 클리어 트리거) |
| 4 | 두 번째 던전 진입 — 3~4 칸 이동 후 "식량이 부족하다" | 자원 학습 (식량 = 생존 자원) |
| 5 | 아빠 대사: "너는 먼저 지상으로 돌아가라" | narrative beat |
| 6 | 귀환 아이템 발동 — 플레이어만 사라짐, 아빠는 남음 | 귀환 메커닉 학습 |
| 7 | 가운데 씬 — 검은 화면 + "시간이 흘렀다 / 그리고 아빠는 돌아오지 않았다" | 사망의 무게 학습 |
| 8 | 길드 홀 첫 진입 (rld_opening_seen 플래그 저장) | 본편 시작 |

## 6. 미정 (Claude Design 의 영역)

다음 사항은 의도적으로 비워둠. Claude Design 이 자유롭게 제안:

### Visual mockup
- 페이지 1, 7 의 검은 화면에서 텍스트 등장 방식 (페이드 / 타이핑 / 정적)
- 페이지 2~3 의 동굴 / 던전 비주얼 — 기존 RLD 던전 픽셀 그대로 vs 오프닝 전용 새 비주얼
- 아빠 NPC 의 외형 — 기존 일러스트 (`opening-art.js` 의 `renderManInDungeon` / `renderManLeaving`) 재활용 가능 여부
- "Clear" 메시지의 시각 처리 — 화면 중앙 / 좌측 / 페이드 톤
- "식량이 부족하다" 시스템 메시지의 톤 — 붉은 톤 / 흰 톤 / 깜빡임 등
- 페이지 6 의 귀환 연출 — 빛 발산 + 페이드 / 다른 시각 처리

### Narrative 보강
- V1 의 대사 4 줄 중 유지할 것 / 다시 쓸 것 / 새로 만들 것
- 페이지 2 의 시작 대사 ("출구를 향해 가자" 정도가 적절한지)
- 페이지 5 의 아빠 작별 대사 — V1 의 "먼저 지상으로 돌아가 있어, 금방 갈게" 가 미니멀 톤에 맞는가
- 페이지 7 의 가운데 씬 텍스트 — "시간이 흘렀다 / 그리고 아빠는 돌아오지 않았다" 가 적절한가, 더 짧게 가능한가

### UI / UX 디테일
- hint 등장 위치 (화면 하단 / 컨텍스트 옆 / 시작 시점에만)
- transition 길이 (페이드 ms, 메시지 머묾 시간)
- "스페이스 / 엔터로 진행" 같은 입력 안내 시점
- 대사 등장 속도 — 일괄 / 타이핑

### Interaction 흐름 검토
- 페이지 2 의 "첫 이동 후 대사" 가 적절한 트리거인가
- 페이지 4 의 "3~4 칸 이동 후 식량 부족" — 칸 수가 적절한가, 다른 트리거 (방향 전환 / 시간 경과) 가 더 자연스러운가
- 페이지 6 의 귀환 — 자동 발동 / 입력으로 발동
- 어디서든 ESC 로 스킵 허용할지 (V1 은 rld_opening_seen 플래그로 1회 후 자동 스킵만 있음)
