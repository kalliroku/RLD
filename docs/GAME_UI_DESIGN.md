## 0. 게임플레이 철학

### 핵심 체험
유저는 **파티장**이다. 직접 싸우지 않는다.
세르파(AI)를 보내고, 지시하고, 때로는 직접 길을 보여준다.

### 코어 루프
```
세르파 파견 (예산 배정)
    → 맵이 밝혀짐 (탐사 진행)
    → 유저가 모니터링 (맵 + 정책 시각화)
    → 필요 시 직접 개입 (수동 탐사, LfD)
    → 던전 클리어 → 최적 경로 확보 → 기계적 파밍
```

### 온보딩: "보여주고 → 좌절시키고 → 개입시키고 → 깨닫게"
Ch.1(Lv.1~4)은 스크립트 튜토리얼. 핵심 메커니즘을 체험으로 가르침.
이후는 유저가 스스로 depth를 발견.

### 핵심 시스템: 트라이 ≠ 에피소드

```
게임 개념            내부 실제
──────              ──────
1 트라이 (재화 소모)  = N 에피소드 (배치 학습)
                      N = 세르파의 "민첩" 스탯

Q군 (민첩 5):   1트라이 = 5ep 학습   → 싸고 느림
다이나 (민첩 12): 1트라이 = 12ep 학습  → 비싸고 빠름
스위퍼 (민첩 15): 1트라이 = 15ep 학습  → 가장 효율적
```

모든 세르파의 **1트라이 = 동일한 현실 시간**. 비싼 세르파가 빠른 이유는
"같은 시간에 더 많이 배워서"이지 UI 속도가 빠른 게 아님.

## 5. Dungeon Screen — 세로 레이아웃

**핵심 변경**: 맵은 하나(전 AI 합산), AI별 "메모"(Q-테이블)는 따로.

### 5.1 전체 구조

```
┌──────────────────────────────────┐
│ Lv.4 독의 숲   답파 30%          │
│ 밝힌 영역: 18/49 (37%)          │
├──────────────────────────────────┤
│                                  │
│  ┌────────────────────────────┐  │
│  │                            │  │
│  │     DUNGEON MAP            │  │
│  │     (전 AI 합산 — 가장     │  │
│  │      많이 밝힌 상태)        │  │
│  │                            │  │
│  │     [1층] [2층] [3층]      │  │
│  │     (다층 던전 시 탭 전환)  │  │
│  │                            │  │
│  └────────────────────────────┘  │
│                                  │
│ ── 탐사 중 (2명) ── [⏹ 일괄정지] │
│                                  │
│ ┌──────────────────────────────┐ │
│ │ ▶ Q군   4/10  40%      [⏹] │ │ ← 접힌 상태
│ └──────────────────────────────┘ │
│ ┌──────────────────────────────┐ │
│ │ ▼ 사르사  3/8  35%     [⏹] │ │ ← 펼친 상태
│ │                              │ │
│ │  📝 사르사의 메모:            │ │
│ │  ┌────────────────────────┐  │ │
│ │  │ ○ ○ ▓ ✕   │  │ │
│ │  │ ▓ ○ ▓ ✕ ▓ │  │ │
│ │  │ ○ ○ ☠     │  │ │
│ │  │ ▓ ▓ ○ ▓   │  │ │
│ │  │     ○ ▓ ★ │  │ │
│ │  └────────────────────────┘  │ │
│ │  "안전한 곳만 표시됨"          │ │
│ │                              │ │
│ │  [🎮 개입]  [⏹ 중단]          │ │
│ └──────────────────────────────┘ │
│                                  │
│ [🎮 직접 탐사 (합산 맵 사용)]     │
└──────────────────────────────────┘
```

### 5.2 맵 (상단) — 합산 맵

- **전 AI 중 가장 많이 밝힌 값의 합산** = 하나의 공유 맵
- Q군이 (3,2)를 밝히고 사르사가 (5,4)를 밝히면 → 둘 다 보임
- 맵 위 정보: 답파율, 밝힌 영역 비율
- 다층 던전: [1층] [2층] [3층] 탭으로 전환
- 25×25, 50×50 등 큰 맵: 스크롤로 보기
- 수동 탐사/직접 개입 시 이 합산 맵을 들고 진입

### 맵 시각화 레이어

```
Layer 0: 안개 (미탐사 = 어둡게)
Layer 1: 타일 (방문 시 공개 — 벽, 함정, 힐, 골드, 몬스터, 골)
Layer 2: 위험 표시 (학습된 위험 칸 — 붉은 기운)
Layer 3: 에이전트 현재 위치 (트라이 중일 때)
```

맵에는 정책(화살표)을 표시하지 **않음**.
정책은 각 AI의 "메모"에서만 보임 → 맵과 메모의 역할 분리.

### 5.3 탐사 목록 (중단) — AI 카드

"탐사 중" 헤더 + [일괄정지] 버튼.

각 AI는 아코디언 카드:
- **접힌 상태**: `세르파명 | 진행바 | 트라이수 | 진척% | [⏹]`
- **펼친 상태**: + 해당 AI의 "메모" (Q-테이블 시각화) + [개입] [중단]

### 5.4 AI별 "메모" — Q-테이블의 게임적 번역

Q-테이블이 뭔지 모르는 사람에게 **"이 세르파가 정리한 공략 노트"**로 보이게.
각 알고리즘 특성에 맞춘 메모 스타일:

#### Q군의 메모 — "방향 낙서"
```
┌─┬─┬─┬─┬─┐
│→│→│▓│↓│?│  자신감 있는 화살표
│▓│↓│▓│↓│▓│  "이쪽이야!" 느낌
│ │→│→│→│↓│  가끔 틀린 방향도 당당하게
│▓│▓│ │▓│↓│  ? = 아직 모름
│ │ │ │▓│★│
└─┴─┴─┴─┴─┘
직선적. 굵은 화살표. 낙관적.
```

#### 사르사의 메모 — "위험 지도"
```
┌─┬─┬─┬─┬─┐
│○│○│▓│✕│ │  ○ = 안전 확인
│▓│○│▓│✕│▓│  ✕ = 절대 안 감
│○│○│☠│ │ │  ☠ = 여기서 당했음
│▓│▓│○│▓│ │  빈칸 = 겁나서 안 가봄
│ │ │○│▓│★│
└─┴─┴─┴─┴─┘
방향보다 "어디가 위험한지"가 핵심.
```

#### 몬테의 메모 — "완주 일지"
```
┌─┬─┬─┬─┬─┐
│●│·│▓│ │ │  ● = 성공한 경로 위의 칸
│▓│·│▓│ │▓│  · = 경로의 일부
│ │·│·│·│ │  빈칸 = 완주 못해서 기록 없음
│▓│▓│ │▓│·│  "이 길로 갔더니 됐어"만 기록
│ │ │ │▓│★│
└─┴─┴─┴─┴─┘
경로 중심. 성공한 루트만 선명.
```

#### 그래디의 메모 — "감 메모"
```
┌─┬─┬─┬─┬─┐
│→│↗│▓│↓│ │  화살표가 대략적 (정확한 방향 아님)
│▓│?│▓│?│▓│  ? = 아직 감이 안 옴
│ │→│~│↘│ │  ~ = 여기는 좀 애매...
│▓│▓│ │▓│ │  전체적으로 흐릿하고 불확실
│ │ │ │▓│★│
└─┴─┴─┴─┴─┘
확률적. 방향이 매번 약간 다를 수 있음.
```

#### 트레이서의 메모 — "발자국 흔적"
```
┌─┬─┬─┬─┬─┐
│◦│◦│▓│ │ │  ◦ = 지나간 흔적
│▓│◦│▓│ │▓│  ◦◦◦ = 자주 지나간 길 (진하게)
│◦│◦│☠│ │ │  ☠에서 뒤로 빨간 흔적 번짐
│▓│▓│◦│▓│ │  실패 → 이 길 전체에 경고 전파
│ │ │◦│▓│★│
└─┴─┴─┴─┴─┘
경로 위에 잔상. 실패 흔적이 역방향 전파.
```

#### 다이나의 메모 — "상상 + 현실"
```
┌─┬─┬─┬─┬─┐
│→│→│▓│↓│~│  실선 = 실제 경험
│▓│↓│▓│~│▓│  ~ = 상상으로 추정 (안 가봤지만)
│ │→│→│~│~│  다른 세르파보다 빈칸이 적음
│▓│▓│ │▓│~│  상상이 틀릴 수도 있음
│ │ │ │▓│★│
└─┴─┴─┴─┴─┘
실제 경험 + 모델 기반 추정이 섞임.
```

#### 크리틱의 메모 — "평점표"
```
┌─┬─┬─┬─┬─┐
│A│B│▓│D│ │  A~F 등급 (칸의 가치)
│▓│A│▓│F│▓│  A = 좋은 위치
│B│A│F│C│ │  F = 최악
│▓│▓│B│▓│ │  방향 대신 "여기가 좋은 곳인가" 위주
│ │ │C│▓│★│  Actor(방향)와 Critic(평가) 분리
└─┴─┴─┴─┴─┘
등급 + 방향이 이중 레이어로.
```

#### QV군의 메모 — "검증된 방향"
```
Q군과 비슷한 화살표, 단 과대평가 없이 정직한 색감.
화살표 굵기 = 확신도. Q군보다 얇고 정확한 화살표.
```

#### 아클라의 메모 — "변덕 일기"
```
화살표가 갑자기 바뀔 수 있음.
이전 트라이와 비교해서 바뀐 칸이 깜빡이는 표시.
"아까는 오른쪽이었는데 이제 아래로?"
```

#### 에크사의 메모 — "계산표"
```
Q군과 비슷한 화살표, 단 더 안정적.
분산 없는 업데이트로 화살표가 덜 흔들림.
"흔들리지 않는 계산기"
```

#### 더블Q의 메모 — "교차 검증"
```
두 가지 색의 화살표가 겹침 (A의 판단 / B의 판단).
둘이 일치하면 굵게, 불일치하면 얇게.
```

#### 앙상블의 메모 — "회의록"
```
여러 색이 겹쳐 보이는 화살표.
5명 합의 = 굵고 선명.
의견 갈림 = 여러 방향 겹쳐서 흐릿.
```

#### 트리백의 메모 — "선견 지도"
```
화살표 + 점선으로 n걸음 앞까지 예측선.
"여기서 가면 → 저기 → 저기 → 골" 식의 계획 표시.
```

#### 스위퍼의 메모 — "우선순위 파동"
```
골 근처부터 시작점으로 퍼져나가는 파동 표시.
번호(①②③)로 업데이트 순서.
한번에 확 채워지는 극적인 순간.
```

- AI가 이전에 밝힌 타일은 **Fog 해제 상태**로 시작
- 유저가 새로 밝힌 타일도 영구 기록
- 유저의 이동 = LfD 학습 데이터로 자동 수집
- 클리어 후 → 성공 경로가 AI 학습에 반영

## 11. 맵과 메모의 관계

### 이원 구조: 맵(공유) vs 메모(개별)

```
맵 (상단, 하나)          메모 (하단, AI별)
──────────────          ──────────────
전 AI 합산              각 AI 고유
타일 공개 + 위험 표시     정책/가치/전략 표시
"어디가 밝혀졌나"        "이 세르파는 어떻게 생각하나"
유저 탐사에도 사용        유저가 AI 이해하는 창구
```

### 맵 합산 규칙
- 안개 해제: 전 AI 중 **하나라도 방문한 칸** → 밝혀짐
- 위험 표시: **하나라도 위험을 학습한 칸** → 빨간 표시
- 타일 종류: 방문한 순간 확정 공개

### 메모 표시 규칙
- 각 AI 카드를 펼치면 해당 AI의 Q-테이블을 메모 스타일로 표시
- 같은 던전에서 여러 AI를 돌리면 → 메모를 비교하며 전략 판단 가능
- "Q군은 오른쪽이라는데 사르사는 위험하다고 하네... 직접 가볼까?"

### 비주얼 레퍼런스
테이블탑 던전 타일 (모듈러 그리드, 방+오브젝트) 스타일 참고.
- 각 칸이 "방" — 벽으로 둘러싸인 작은 공간
- 밝혀진 방: 따뜻한 색 (조명 있음)
- 미탐사 방: 어둡거나 안 보임 (안개)
- 메모 표시: 방 위에 떠 있는 반투명 마커/화살표 오버레이

## 12. 경제 공식

### 트라이 비용
```
1트라이 비용 = 운영비(캐릭터) × sqrt(던전레벨)

예) Q군(3G) × Lv.4 → 3 × 2 = 6G/트라이
예) 스위퍼(7G) × Lv.4 → 7 × 2 = 14G/트라이
```

### 필요 트라이 수
```
필요 에피소드 ÷ 민첩 = 필요 트라이

예) 200ep ÷ 민첩5 = 40트라이 (Q군)
예) 200ep ÷ 민첩15 = 14트라이 (스위퍼)
```

### 총비용 비교 (Lv.4, 200ep 필요 가정)
```
Q군:     40트라이 × 6G = 240G (느림, 저렴/트라이)
다이나:   17트라이 × 12G = 204G (빠름, 비쌈/트라이)
스위퍼:   14트라이 × 14G = 196G (가장 빠름, 효율적)
앙상블:   20트라이 × 16G = 320G (안정적, 비쌈)
```

*실제 수치는 밸런싱 단계에서 조정*
